## Minimum Assets for Final Image Generation

Request at least these before making upload-ready images:

- app icon
- 3-6 clean gameplay captures at final or higher resolution
- one clear differentiator statement
- target store and orientation
- target language
- banned claims and banned visuals

If these are unavailable, create a concept board and prompt pack first, then ask for captures before final export.
